Wraith for Odysseus puts your own self-hosted Odysseus AI server on your phone: your chats, your email and your tools.

Unofficial, not affiliated with the Odysseus project.

Requires your own Odysseus server (tested with 1.0.3). The app talks to it over the same routes its web UI uses, so the server needs no changes.

Chats:
* every chat session, with search and new chats
* streaming replies, with the model's thinking shown separately
* model picker, and agent, web and research modes
* approve or deny tool calls; a Terminal toggle for accounts allowed to use it
* photo and file attachments
* stop a reply, or switch away and come back: a running reply is picked up again from the server without doubled text
* sources, tool cards, timings and reply variants
* hold a message to copy, edit, resend, regenerate, fork, rewrite or delete it
* hold a chat to rename, favourite, copy, move to a folder, archive or delete it

Email:
* all your accounts, with folders, filters and search
* HTML mail, with images loaded only when you ask
* attachments, and mark unread
* send, reply, reply all and forward
* translate, schedule send and AI reply

Tools:
* Notes, Calendar, Memory, Skills, Deep Research, Tasks, Gallery, Library and Theme
* Compare and Cookbook open the web UI

You log in with your Odysseus username, password and 2FA code, just as in the web UI. Only the resulting session cookie is stored, encrypted with a key that never leaves the device. Your password is never stored.

https only: plain http is refused, so your session is never sent unencrypted. On a tailnet, Tailscale's https certificates for *.ts.net names work as is.

Update check: builds downloaded from this project's releases check its Gitea releases page once per launch and offer a link when a newer version exists. Nothing about you or your server is sent. When F-Droid installed the app the check is off, and it contacts nothing but your own server.

No analytics, no tracking, no Google Play Services. The only permission is Internet access.

Not distributed via Google Play. Besides F-Droid, it is on this project's Gitea releases, which Obtainium can track. Builds are reproducible: F-Droid ships the same APK, signed with the same key, so all three update each other.
